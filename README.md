# gym-diary

운동 자세 가이드와 수업 기록을 모아두는 레포입니다.

## 공개 사이트

- `site/` 폴더만 GitHub Pages로 배포됩니다. 사이트 주소는 Pages 활성화 후 확인하세요.
- 사이트에는 운동 이름, 자세 순서, 기구, 코칭 문구가 들어 있습니다.
- 인바디 수치 등 개인 건강 기록은 공개 사이트에 넣지 않았습니다.

## 날짜별 기록

- `records/` 폴더에 수업일지 날짜별 파일이 있습니다.
- 각 파일은 수업일지에 기록된 1세트 기준 무게·횟수와 코칭을 옮긴 것입니다.
- 날짜가 잘린 하체 세션은 `records/undated-leg-session.md`로 따로 두었습니다.

## 개인 기록 (암호화)

- `private/personal-data.md.enc`는 AES-256-CBC(PBKDF2, salt 포함)로 암호화된 개인 기록 파일입니다.
- 이 레포는 공개 레포입니다. 암호화 파일은 누구나 내려받을 수 있고, 복호화 보안은 비밀번호 강도에만 의존합니다. 약한 비밀번호로는 안전하지 않으니, 필요하면 더 강한 비밀번호로 다시 암호화하거나 비공개 레포로 옮기세요.
- 비밀번호는 이 레포 어디에도 저장하지 않습니다.

### 사이트에서 확인하기

- 가이드 메인 페이지의 “개인 기록” 패널에서 “개인 기록 확인하기”를 누르면 팝업이 열립니다. 팝업에서 비밀번호를 입력하면, 비밀번호가 서버로 전송되지 않고 브라우저 안에서만(WebCrypto, PBKDF2 10,000회 + AES-256-CBC) 복호화해 인바디 기록을 보여줍니다. 팝업을 닫으면 복호화된 내용은 사라집니다.
- 메인 페이지에는 평문 수치가 들어 있지 않고, 암호화 데이터(base64)만 들어 있습니다. 팝업 디자인은 가이드의 패널·시트·오렌지 액센트 톤에 맞춰져 있습니다.

### 명령줄에서 복호화하기

복호화 (비밀번호를 물으면 직접 입력):

```sh
openssl enc -d -aes-256-cbc -pbkdf2 -in private/personal-data.md.enc -out personal-data.md
```
